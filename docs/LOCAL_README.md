# 角落有喵

一只住在桌面角落的小猫，一座慢慢长大的窗台花园。原生 macOS 挂机小游戏，带可操作的钓鱼玩法。

## 打开

解压 **角落有喵-macOS.zip**，将 **角落有喵.app** 拖到“应用程序”文件夹，再双击打开。适用于 **Apple Silicon Mac，macOS 14 或更新版本**，不需要安装额外运行环境。

第一次打开会出现小屋，之后会记住上一次的显示模式和窗口位置。应用常驻菜单栏，不占 Dock 图标。左键点击菜单栏爪印显示/隐藏，右键可以切换模式或退出。

## 怎么玩

- **照料**：稳定赚取露珠，收益最高。
- **探索**：Lv.2 解锁；露珠是照料的 65%，经验从每分钟 8 提高到 18。
- **打盹**：恢复心情，也有少量挂机产出。
- **摸摸**：每 15 秒可得 2 露珠、6 经验和 1 亲密度；冷却中也能与小猫互动。
- **喂食**：消耗 12 露珠，增加心情、10 经验和 2 亲密度；冷却 30 秒。
- **钓鱼**：打开“钓鱼”页抛竿。浮标进入浅绿区域时点击“收竿”或按空格，得到 1 分；深绿中心得到 2 分。每局三竿，每竿限时 6 秒。

钓鱼每局奖励为 **3 + 3 × 总分** 露珠，以及 **4 + 2 × 总分** 经验。满分一局 21 露珠、16 经验；满 4 分额外增加亲密度。两次开局至少间隔 45 秒。离开钓鱼页、切换窗口模式或隐藏时，未完成的一局会结束，没有奖励。

推荐开局先摸摸小猫、玩一局钓鱼，再到“升级”购买花盆。升级加快挂机产出；经验自动提升等级，逐步解锁浇水、猫窝、绿植、地毯、灯和星星挂饰。每种升级最多 50 级，摆件在“小物”里购买和切换。

## 小窗与桌宠

| 操作 | 功能 |
| --- | --- |
| 小屋右上角爪印 | 透明桌宠，120 × 120 pt |
| 小屋右上角横线 | 迷你状态条，164 × 34 pt |
| 小屋右上角叉号 | 隐藏窗口，挂机继续 |
| ⌘⇧H | 全局显示 / 隐藏 |
| Esc | 小窗获得键盘焦点时隐藏 |
| 拖动标题 | 移动小屋，大小 320 × 452 pt |
| 拖动桌宠脚下横线 | 移动小猫；双击横线回小屋 |
| 点击状态条数字 | 返回小屋 |
| 拖动状态条左侧圆点 | 移动状态条 |
| 底部图钉 | 开关置顶 |
| 底部圆圈 | 切换 100% / 72% 不透明度 |
| 右键桌宠或状态条 | 模式、显示和退出菜单 |

若 ⌘⇧H 被其他应用占用，小屋底部“？”会提示，菜单栏爪印仍可使用。隐藏不会停止生产，退出应用或电脑休眠后也能结算最多 8 小时收益。小猫不会因为离开而死亡。

## 存档与素材

纯本地运行，不需要账号或联网。每 15 秒、重要操作后和正常退出时保存，使用原子写入和一个备用存档。存档位于 `~/Library/Application Support/CornerCat/save.json`，备用文件是 `save.json.backup`。想转移进度时，先退出应用，再复制这两个文件。

猫咪、场景、摆件和应用图标均为本项目原创代码绘制的像素 / 矢量素材；界面小图标使用 macOS 系统 SF Symbols。没有外部素材下载依赖。

## 源码与构建

`Source` 包含完整 Swift 源码；`Assets/AppIcon.icns` 为图标；`Tools/MakeIcon.swift` 可重新生成图标。

在装有 Xcode Command Line Tools 的 Apple Silicon Mac 中：

```sh
./build.sh
./test.sh
./test.sh --desktop
```

构建产物默认在项目文件夹旁的 `角落有喵.app` 和 `角落有喵-macOS.zip`。脚本在系统临时目录完成签名和校验后压缩，避免同步文件夹附加的 Finder 元数据影响应用包。推荐使用 ZIP 解压到“应用程序”运行。

使用系统 AppKit、SwiftUI、Foundation 和 Carbon，无第三方运行依赖。构建脚本对生成的应用做本地 ad-hoc 签名；这份构建没有 Apple Developer ID 公证，面向当前 Mac 本地运行。
